# LLDM Photo Studio Pro

Aplicación web profesional de edición fotográfica en lote para la iglesia **La Luz del Mundo (LLDM) - Vistas de la Cantera**.

## ✨ Funcionalidades

- 📷 **Procesamiento RAW 14-bit** — Soporte completo para archivos Nikon `.NEF`, Canon `.CR2`, Sony `.ARW` y `.DNG`
- 🎨 **Edición en Lote** — Aplica filtros, marcos y marcas de agua a todo el lote con 1 clic
- 🖼️ **Marcos de Eventos Integrados** — Marcos prediseñados para Escuela Dominical, Cultos y más
- 💧 **Catálogo de Logos PNG Persistente** — Guarda y gestiona tus logos de la iglesia
- 📐 **Recorte Adaptativo Multi-Formato** — Nativo Nikon (3:2), Instagram (4:5), Historias (9:16) y más
- 🖱️ **Re-encuadre con Mouse** — Arrastra la foto de fondo dentro del marco con total precisión
- 📦 **Exportación ZIP en Lote** — Descarga todas las fotos editadas en alta resolución

## 🚀 Tecnologías

- React 19 + TypeScript
- Vite 8
- Canvas HTML5 (motor de renderizado HDR)
- LocalStorage (persistencia de marcos y logos)

## 🛠️ Instalación local

```bash
npm install
npm run dev
```

## 🏗️ Build para producción

```bash
npm run build
npm start
```
